<print-link-list>

Class-only import. See the README for the API.

Read the README View on GitHub All examples unpkg example

This page loads the class from esm.sh and registers it manually. Use your browser’s Print command. If the CDN or JavaScript is unavailable, the original links remain usable without a generated list.

Register the class, then print

import { PrintLinkListElement } from
  'https://esm.sh/@aarongustafson/print-link-list@1.0.3/print-link-list.js?bundle&target=es2022';
customElements.define('print-link-list', PrintLinkListElement);

<div id="reading">
  <a href="https://www.w3.org/TR/css-page-3/">Paged media</a>
  <print-link-list target="#reading"></print-link-list>
</div>
