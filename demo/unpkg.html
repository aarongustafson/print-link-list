<print-link-list> via unpkg

Definition-helper import. See the README for the API.

This page loads the definition helper from unpkg. The helper module registers the element automatically; calling it again is safe. Use your browser’s Print command. If the CDN or JavaScript is unavailable, the original links remain usable without a generated list.

Load the helper, then print

import { definePrintLinkList } from
  'https://unpkg.com/@aarongustafson/print-link-list@latest/define.js?module';
definePrintLinkList();

<div id="reading">

  <print-link-list target="#reading"></print-link-list>
</div>
